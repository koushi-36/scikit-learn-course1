# Scikit-learn Course Projects

A beginner-friendly portfolio of machine learning examples using Python and scikit-learn.

## Projects
1. Linear Regression — predict a numeric value.
2. Logistic Regression — binary classification.
3. Naive Bayes — classification example.
4. Decision Tree — interpretable classification.
5. Hierarchical Clustering — unsupervised grouping.
6. Model Evaluation — train/test split and common metrics.

## Requirements
- Python 3.9+
- pandas
- numpy
- scikit-learn
- matplotlib

Install dependencies:

```bash
pip install -r requirements.txt
```

## Run a project
Open a `.py` file in Python or VS Code and run it. The examples use built-in scikit-learn datasets, so no separate dataset download is required.

## Learning note
These are educational starter examples. Read the comments, run each script, and experiment with the parameters. If you adapt code from tutorials or other repositories, credit the original source.
